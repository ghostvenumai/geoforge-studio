# GeoForge Studio Product Brief

GeoForge Studio is an offline-first enterprise-style platform for repeatable address, coordinate, profiling, deduplication, quality, and export workflows. It demonstrates the full lifecycle expected from a Python Data Processor: safe ingestion, columnar processing, reproducible pipeline configuration, observable execution, reviewable quality outcomes, and auditable artifacts.

## Primary users

- Data engineers designing deterministic transformation pipelines.
- Data stewards reviewing ambiguity and quality regressions.
- Technical stakeholders evaluating throughput, auditability, and architecture.

## Product promises

- Original files remain immutable and checksummed.
- Processing runs are reproducible from dataset checksum plus versioned pipeline YAML.
- Quality improvements are shown together with row loss and quarantine counts.
- Candidate blocking prevents unrestricted quadratic duplicate comparisons.
- Geospatial display and processing use no external map or geocoding service.
- German-language UI works in light/dark modes with keyboard-visible focus.
