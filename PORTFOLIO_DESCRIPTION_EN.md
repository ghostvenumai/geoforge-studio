# Portfolio Description

GeoForge Studio is a production-oriented, offline data-engineering platform for address, geo, and quality workloads. It combines FastAPI, Pydantic, Polars, PyArrow, DuckDB, pyproj, RapidFuzz, SQLAlchemy, and React/TypeScript. It demonstrates secure ingestion, scalable profiling, reproducible visual/YAML pipelines, blocked duplicate matching, quarantine, measured performance, and auditable exports. Its final suite ran 82 Python tests at 92.54% coverage and a passing desktop/tablet/mobile Playwright and axe journey.
