# Loop Goal

Deliver GeoForge Studio as an offline-first, production-oriented address, geospatial, data-quality, and transformation portfolio platform. A release is complete only when the React UI, FastAPI backend, processing engine, audit artifacts, tests, accessibility checks, benchmark evidence, containers, screenshots, and honest final report satisfy the acceptance criteria in `PRODUCT_BRIEF.md`.

The loop is bounded by `max_iterations` in `LOOP_STATE.json`, stops after three identical failure signatures, and never requests elevated access.
